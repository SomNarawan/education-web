FE API ENDPOINTS
================

ตรวจจาก source code ของ education-web ณ วันที่ 2026-08-01

Base URL
--------
VITE_API_URL=http://localhost:8000/api

Request headers
---------------
Content-Type: application/json
Authorization: Bearer {auth_token}   (ส่งเมื่อมี auth_token ใน localStorage)

หมายเหตุ
--------
- รายการนี้แยกตามรูปแบบ request ที่ FE เรียกจริง แม้จะใช้ method และ path เดียวกัน
- query parameter ที่ไม่มีค่า/เป็นค่าว่างจะไม่ถูกส่ง
- {id}, {studentCode}, {teacherId}, {departmentId} และ {facultyId} เป็นค่าที่เปลี่ยนตามข้อมูลผู้ใช้
- /auth/callback เป็น route ของ Frontend ไม่ใช่ API request

2. STUDENT LIST: รูปแบบการเรียก GET /students
================================================

[2] หน้านิสิตในที่ปรึกษา: โหลดครั้งแรก
Method: GET
Path: /students
Query:
  teacher_id={teacherId ของผู้ใช้ที่ login}       required
  student_status_id=2                            ค่าเริ่มต้น
ตัวอย่าง:
  GET /students?teacher_id=10&student_status_id=2

[3] หน้านิสิตในที่ปรึกษา: ค้นหาด้วยสถานะ/Note
Method: GET
Path: /students
Query:
  teacher_id={teacherId ของผู้ใช้ที่ login}       required
  student_status_id={studentStatusId}             optional
  search_note={noteType หรือข้อความ Note}         optional
ตัวอย่าง:
  GET /students?teacher_id=10&student_status_id=2&search_note=ติดตาม

[4] หน้านิสิตในที่ปรึกษา: ล้างตัวกรอง
Method: GET
Path: /students
Query:
  teacher_id={teacherId ของผู้ใช้ที่ login}       required
ตัวอย่าง:
  GET /students?teacher_id=10

[5] หน้านิสิตในภาควิชา (Teacher): โหลดครั้งแรก
Method: GET
Path: /students
Query:
  department_id={departmentId ของผู้ใช้ที่ login} required
  student_status_id=2                             ค่าเริ่มต้น
ตัวอย่าง:
  GET /students?department_id=20&student_status_id=2

[6] หน้านิสิตในภาควิชา: ค้นหาด้วยสถานะ/Note
Method: GET
Path: /students
Query:
  department_id={departmentId}                    required
    - Teacher: ใช้ departmentId ของผู้ใช้ที่ login
    - Admin: ใช้ภาควิชาที่เลือกจากหน้าจอ
  student_status_id={studentStatusId}              optional
  search_note={noteType หรือข้อความ Note}          optional
ตัวอย่าง:
  GET /students?department_id=20&student_status_id=2&search_note=อื่นๆ

[7] หน้านิสิตในภาควิชา (Teacher): ล้างตัวกรอง
Method: GET
Path: /students
Query:
  department_id={departmentId ของผู้ใช้ที่ login} required
ตัวอย่าง:
  GET /students?department_id=20

[8] หน้านิสิตในคณะ: ค้นหาจากข้อความ
Method: GET
Path: /students
Query:
  faculty_id={facultyId ของผู้ใช้ที่ login}        required
  search_text={ข้อความค้นหาที่ trim แล้ว}          required จากหน้าจอ
ตัวอย่าง:
  GET /students?faculty_id=30&search_text=สมชาย

ข้อสังเกตของ GET /students
-------------------------
- FE ไม่มีการเรียก GET /students แบบไม่มี query parameter
- หน้าในคณะไม่โหลดรายชื่อทันที ต้องกรอก search_text แล้วกดค้นหาก่อน
- search_text ถูกใช้เฉพาะหน้าค้นหานิสิตในคณะ
- search_note ถูกใช้ในหน้านิสิตในที่ปรึกษาและหน้านิสิตในภาควิชา

=======

- รูปแบบ request ที่แยกรายการไว้: 34 รายการ

- API client: src/config/axios.ts
- API services: src/services/*.ts
- GET /me เรียกโดย src/context/AuthContext.tsx
